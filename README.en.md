# modavd.github.io

This repository contains the ModAVD documentation site. The site is built with VitePress from `docs/` and published as the English and Simplified Chinese guides at [modavd.github.io](https://modavd.github.io/).

```sh
npm ci
npm run build
```

Chinese pages live under `docs/` and English pages under `docs/en/`. Keep both versions aligned when changing navigation, links or technical instructions. Public documentation must not contain accounts, keys, private paths or test data.
