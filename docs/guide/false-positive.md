# 杀毒软件误报怎么办

偶尔会有杀毒软件把 ModAVD 的文件报成木马。可以先按下面的步骤确认文件来源和完整性，再决定是否放行。

## 为什么会误报

ModAVD 的程序没有商业代码签名。个别杀毒软件的机器学习规则会偶尔把没有这类签名的程序判成木马，Windows Defender、Kaspersky 都出现过这种误报。

## 先确认下载的是正版

1. 只从 [ModAVD Releases](https://github.com/ModAVD/ModAVD/releases) 下载压缩包，同时下载同一发布页上的 `SHA256SUMS`。
2. 在保存压缩包的文件夹里打开 PowerShell，运行下面的命令，把文件名换成实际下载的文件名：

   ```powershell
   Get-FileHash .\ModAVD-<版本>-win-x64.zip -Algorithm SHA256
   ```

3. 把命令输出的 `Hash` 和 `SHA256SUMS` 里对应文件的哈希对照。两边完全一致，才继续解压和使用；不一致就删除压缩包，重新从发布页下载。

## Windows Defender 怎么放行

### 恢复被隔离的文件

1. 打开「Windows 安全中心」→「病毒和威胁防护」→「保护历史记录」。
2. 找到报告 ModAVD 的记录，打开详情，确认路径和文件名属于你刚才核对过的发布包。
3. 选择「操作」→「在设备上允许」或「恢复」，按提示完成。

### 加排除项

1. 打开「Windows 安全中心」→「病毒和威胁防护」→「管理设置」→「排除项」→「添加或删除排除项」。
2. 选择「添加排除项」→「文件夹」，选中解压后的 ModAVD 根目录。
3. 保存设置后再运行 ModAVD。

排除项只加 ModAVD 根目录，不要把整块磁盘或整个用户目录加入排除项。

## Kaspersky 怎么加信任

1. 打开 Kaspersky，进入「设置」→「安全设置」→「威胁和排除项」→「管理排除项」（不同产品版本的菜单名称可能略有不同）。
2. 点击「添加」，选择解压后的 ModAVD 根目录。
3. 确认对这个文件夹启用信任或不扫描其中的文件，保存设置后再运行 ModAVD。

同样只添加 ModAVD 根目录，不要放行整块磁盘。

## 仍然被误报时怎么反馈

到 [ModAVD 仓库的 Issues](https://github.com/ModAVD/ModAVD/issues) 提交问题，并写明：

- 杀毒软件名称和版本；
- 检测到的名称（例如木马名称）；
- 被拦截的文件名，以及对应发布版本；
- 如果方便，附上 `SHA256SUMS` 的核对结果和检测截图。
