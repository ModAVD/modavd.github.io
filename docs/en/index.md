# ModAVD

ModAVD is a modified build of the AOSP Android Emulator (37.2.10) for Windows, with a focus on unattended automation. It is commonly integrated with the independent [AUTO-MAS](https://github.com/AUTO-MAS-Project/AUTO-MAS) project, and the 0.36.0 package also includes a manager and CLI that can manage instances without AUTO-MAS. This describes compatibility, not a formal partnership or joint maintenance arrangement. Most of this site is in Chinese; this page is a short summary.

- **Privacy in the published 0.36.0 package**: the emulator build disables usage-metrics upload, crash-report upload, update checks, and feature-pattern downloads. Crash dumps stay on the host. The Location page of the extended controls can still load Google Maps when opened in windowed mode. The Android system and its apps use the network as usual. This is a description of the current release, not a permanent promise for future versions.
- **Requirements**: Windows 10/11 64-bit, an x86_64 CPU with virtualization enabled, the Windows Hypervisor Platform (WHPX) feature, and a GPU with Vulkan drivers.
- **Install**: download the release zip from [Releases](https://github.com/ModAVD/ModAVD/releases), extract it to a path with ASCII characters only, run `补全组件.bat` (it shows the Android SDK License Agreement and downloads adb and the Android 14 system image from Google's official channels after you accept), then either add the folder in AUTO-MAS or point the bundled manager/CLI at it. From 0.36.0 the package also has a manager (`ModAVD.exe`) and a CLI with an MCP server (`tools\modavd.exe`).
- **Components**: the emulator patches, the arm64 execution bridge and the bundled scripts live in [ModAVD/ModAVD](https://github.com/ModAVD/ModAVD); the manager and CLI in [ModAVD/ModAVDManager](https://github.com/ModAVD/ModAVDManager); the host IME in [ModAVD/ModAVDHostIME](https://github.com/ModAVD/ModAVDHostIME).
