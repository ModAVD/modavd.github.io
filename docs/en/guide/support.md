# Support

ModAVD is free and open source. A donation buys no extra features and no priority support.

If it has been useful and you would like to give something, you can donate on Afdian (WeChat Pay and Alipay) to help cover the cost of development: <https://ifdian.net/a/qiyinxi>

You can also help at no cost: tell others if it works well for you, and report problems as described in [Report a problem](feedback).
